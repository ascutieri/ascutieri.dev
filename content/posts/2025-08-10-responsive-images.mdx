# Responsive Images: Modern Techniques

Proper image optimization significantly improves performance.

## Picture Element

```html
<picture>
  <source media="(min-width: 1200px)" srcset="large.webp">
  <source media="(min-width: 768px)" srcset="medium.webp">
  <source media="(min-width: 320px)" srcset="small.webp">
  <img src="fallback.jpg" alt="Description">
</picture>
```

## Srcset Attribute

```html
<img
  src="image-600w.jpg"
  srcset="
    image-300w.jpg 300w,
    image-600w.jpg 600w,
    image-1200w.jpg 1200w"
  sizes="(max-width: 600px) 100vw, 50vw"
  alt="Description"
/>
```

## Image Formats

| Format | Size | Browser Support |
|--------|------|-----------------|
| JPEG | Medium | Excellent |
| PNG | Large | Excellent |
| WebP | Small | Modern |
| AVIF | Smallest | Growing |

## Best Practices

```html
<!-- Lazy loading -->
<img src="image.jpg" loading="lazy" alt="Description">

<!-- Aspect ratio -->
<img src="image.jpg" width="800" height="600" alt="Description">

<!-- Responsive -->
<img src="image.jpg" sizes="100vw" srcset="..." alt="Description">
```
