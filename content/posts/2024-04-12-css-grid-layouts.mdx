CSS Grid is a powerful layout system for creating complex responsive designs. Let's explore how to use it effectively.

## Grid Basics

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-gap: 20px;
    padding: 20px;
}

.item {
    background-color: #3498db;
    padding: 20px;
    color: white;
}
```

## Template Areas

Create semantic layouts with named areas:

```css
.page {
    display: grid;
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
    grid-template-columns: 250px 1fr 1fr;
    grid-gap: 10px;
    height: 100vh;
}

header { grid-area: header; }
.sidebar { grid-area: sidebar; }
main { grid-area: main; }
footer { grid-area: footer; }
```

## Responsive Grid

### Mobile-First Approach

```css
/* Mobile: 1 column */
.grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 15px;
}

/* Tablet: 2 columns */
@media (min-width: 768px) {
    .grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Desktop: 3 columns */
@media (min-width: 1024px) {
    .grid {
        grid-template-columns: repeat(3, 1fr);
    }
}
```

## Grid Properties Comparison

| Property | Purpose | Example |
|----------|---------|---------|
| `grid-template-columns` | Define column sizes | `1fr 2fr 1fr` |
| `grid-template-rows` | Define row sizes | `100px 1fr 100px` |
| `grid-gap` | Space between items | `20px` |
| `grid-auto-flow` | Item placement order | `row` \| `column` |
| `justify-items` | Horizontal alignment | `center` \| `start` \|end` |
| `align-items` | Vertical alignment | `center` \| `start` \| `end` |

## Real-World Example

```css
/* Blog layout */
.blog-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 30px;
    padding: 40px 20px;
}

.blog-card {
    background: white;
    border-radius: 8px;
    overflow: hidden;
    box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

.blog-card img {
    width: 100%;
    height: 200px;
    object-fit: cover;
}
```

## Grid vs Flexbox

| Feature | Grid | Flexbox |
|---------|------|---------|
| Layout Type | 2-Dimensional | 1-Dimensional |
| Use Case | Page layouts | Component layouts |
| Browser Support | Modern browsers | All modern browsers |
| Complexity | Better for complex | Better for simple |
