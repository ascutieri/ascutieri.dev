# Machine Learning in Web Development

ML is becoming accessible to web developers. Let's explore it.

## TensorFlow.js

```javascript
import * as tf from '@tensorflow/tfjs';

// Create a simple model
const model = tf.sequential({
  layers: [
    tf.layers.dense({ units: 10, activation: 'relu', inputShape: [4] }),
    tf.layers.dense({ units: 3, activation: 'softmax' })
  ]
});

// Compile
model.compile({
  optimizer: tf.train.adam(0.01),
  loss: 'categoricalCrossentropy',
  metrics: ['accuracy']
});
```

## Common Use Cases

```javascript
// Image classification
const predictions = model.predict(tf.tensor4d([image]));

// Text classification
const embedding = tf.layers.embedding().apply(tokens);
```
