# Webpack vs Vite: Modern Module Bundlers Compared

Choosing the right bundler is crucial for your build process. Let's compare two popular options.

## Speed Comparison

```bash
# Vite - Lightning fast
npm run dev    # < 100ms

# Webpack - Still powerful
npm run dev    # 500ms-2s
```

## Configuration

### Vite (Simple)

```javascript
export default {
  server: {
    port: 3000
  }
}
```

### Webpack (Complex)

```javascript
module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
  },
  module: {
    rules: [/* ... */]
  }
}
```

| Feature | Vite | Webpack |
|---------|------|---------|
| Setup | 5 min | 30 min |
| Build Speed | ⚡ Very Fast | Fast |
| Config Complexity | Simple | Complex |
| Ecosystem | Growing | Mature |

## When to Use Each

**Vite:**
- Modern projects
- Fast development
- React, Vue, Svelte

**Webpack:**
- Complex requirements
- Mature ecosystem
- Legacy projects

---

Choose Vite for new projects, Webpack for complex needs!
