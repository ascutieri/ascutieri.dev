# Tailwind CSS: Utility-First Styling

Tailwind CSS revolutionizes how we write styles. Let's master it.

## Basic Button

```html
<button class="px-4 py-2 bg-blue-500 text-white rounded hover:bg-blue-600">
  Click me
</button>
```

## Responsive Design

```html
<div class="text-sm md:text-base lg:text-lg">
  Responsive text
</div>
```

## Dark Mode

```html
<div class="bg-white dark:bg-slate-900 text-black dark:text-white">
  Content
</div>
```

## Key Benefits

| Benefit | Impact |
|---------|--------|
| No CSS files | Faster development |
| Consistency | Design system built-in |
| No naming | PurgeCSS removes unused |
| Rapid prototyping | Ideas to code in seconds |

## Common Utilities

```html
<!-- Spacing -->
<div class="m-4 p-8 gap-2">Margin, padding, gap</div>

<!-- Colors -->
<div class="bg-red-500 text-blue-600">Colors</div>

<!-- Layout -->
<div class="flex justify-center items-center">Layout</div>
```
