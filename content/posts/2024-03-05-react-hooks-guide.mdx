React Hooks revolutionized how we write components. Let's explore the most common hooks and how to use them.

## useState Hook

The most fundamental hook for managing state:

```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  );
}
```

## useEffect Hook

Handle side effects in functional components:

```jsx
import { useEffect, useState } from 'react';

function UserProfile({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch(`/api/users/${userId}`)
      .then(res => res.json())
      .then(data => {
        setUser(data);
        setLoading(false);
      });
  }, [userId]);

  if (loading) return <p>Loading...</p>;
  return <h1>{user?.name}</h1>;
}
```

## Common Hooks

| Hook | Purpose | Example Use |
|------|---------|------------|
| `useState` | Manage component state | Form inputs, counters |
| `useEffect` | Handle side effects | Data fetching, subscriptions |
| `useContext` | Access context values | Theme, authentication |
| `useReducer` | Complex state logic | Shopping cart, form state |
| `useMemo` | Memoize calculations | Expensive computations |
| `useCallback` | Memoize functions | Callback optimization |

## Best Practices

1. **Only call hooks at the top level**
   - Don't call them inside loops, conditions, or nested functions

2. **Only call hooks from React components**
   - Call them from functional components or custom hooks

3. **Use the ESLint plugin**
   - Install `eslint-plugin-react-hooks` to catch mistakes

4. **Create custom hooks**
   - Extract logic into reusable hooks

### Example Custom Hook

```jsx
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    fetch(url)
      .then(res => res.json())
      .then(data => {
        setData(data);
        setLoading(false);
      })
      .catch(err => {
        setError(err);
        setLoading(false);
      });
  }, [url]);

  return { data, loading, error };
}
```

## Tips & Tricks

- Use the Rules of Hooks consistently
- Combine multiple hooks for more complex logic
- Consider `useCallback` when passing callbacks to optimized child components
- Profile performance with React DevTools
