# Code Quality: ESLint and Prettier

Consistent code quality improves team productivity. Let's set it up.

## ESLint Configuration

```javascript
// .eslintrc.js
module.exports = {
  env: {
    node: true,
    es2021: true
  },
  extends: 'eslint:recommended',
  rules: {
    'no-unused-vars': 'error',
    'no-console': 'warn',
    'semi': ['error', 'always']
  }
};
```

## Prettier Configuration

```javascript
// prettier.config.js
module.exports = {
  semi: true,
  singleQuote: true,
  tabWidth: 2,
  trailingComma: 'es5'
};
```

## npm Scripts

```json
{
  "scripts": {
    "lint": "eslint src/**/*.js",
    "format": "prettier --write src/**/*.js",
    "lint:fix": "eslint src/**/*.js --fix"
  }
}
```

## Benefits

| Benefit | Impact |
|---------|--------|
| Consistency | Same code style |
| Early errors | Catch issues early |
| Auto-fix | Save manual fixing |
| Team alignment | Everyone on same page |
