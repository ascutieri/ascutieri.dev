# Building CLI Tools with Node.js

Command-line tools are powerful. Let's build them with Node.js.

## Basic CLI

```javascript
#!/usr/bin/env node

const args = process.argv.slice(2);

if (args[0] === 'help') {
  console.log('Usage: mytool [command]');
}
```

## With Commander.js

```javascript
const { program } = require('commander');

program
  .command('create <name>')
  .description('Create new project')
  .action((name) => {
    console.log(`Creating ${name}...`);
  });

program.parse(process.argv);
```

| Package | Purpose |

## Building and Publishing

```bash
# Make executable
chmod +x bin/index.js

# Link locally
npm link

# Publish
npm publish
```
