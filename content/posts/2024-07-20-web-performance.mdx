## Core Web Vitals

Google's metrics for measuring website quality:

| Metric | Measure | Good | Poor |
|--------|---------|------|------|
| LCP | Largest Contentful Paint | < 2.5s | > 4s |
| FID | First Input Delay | < 100ms | > 300ms |
| CLS | Cumulative Layout Shift | < 0.1 | > 0.25 |

## Image Optimization

### Responsive Images

```html
<!-- Use srcset for different screen sizes -->
<img
  src="image-400w.jpg"
  srcset="
    image-400w.jpg 400w,
    image-800w.jpg 800w,
    image-1200w.jpg 1200w"
  sizes="(max-width: 600px) 100vw, 50vw"
  alt="Description"
/>

<!-- Use picture for different formats -->
<picture>
  <source srcset="image.webp" type="image/webp" />
  <source srcset="image.png" type="image/png" />
  <img src="image.png" alt="Description" />
</picture>
```

## Code Splitting

### Dynamic Imports

```javascript
// Instead of loading everything at once
import { heavyModule } from './heavy'; // ❌ Large bundle

// Load only when needed
const loadHeavy = async () => {
  const { heavyModule } = await import('./heavy');
  return heavyModule;
};
```

## Caching Strategies

```javascript
// Cache bust with version hash
<script src="/app.abc123.js"></script>

// Service Worker caching
self.addEventListener('install', event => {
  event.waitUntil(
    caches.open('v1').then(cache => {
      return cache.addAll([
        '/',
        '/styles/main.css',
        '/scripts/app.js'
      ]);
    })
  );
});
```

## Performance Checklist

- [ ] Minimize JavaScript bundles
- [ ] Optimize images (use WebP, compress)
- [ ] Enable GZIP compression
- [ ] Implement lazy loading
- [ ] Use CDN for static assets
- [ ] Minimize CSS and JavaScript
- [ ] Remove unused dependencies
- [ ] Set appropriate cache headers
- [ ] Defer non-critical JavaScript
- [ ] Monitor with tools like Lighthouse
