TypeScript adds type safety to JavaScript, helping catch bugs before runtime. Let's explore best practices.

## Type Definitions

### Explicit Types

```typescript
// ❌ Avoid implicit any
function processData(data) {
  return data.value * 2;
}

// ✅ Use explicit types
function processData(data: { value: number }): number {
  return data.value * 2;
}
```

## Interfaces vs Types

| Aspect | Interface | Type Alias |
|--------|-----------|-----------|
| Syntax | `interface Name {}` | `type Name = {}` |
| Extends | Yes | Yes |
| Merge | Yes | No |
| Union | No | Yes |
| Best For | Objects | Unions, primitives |

### Examples

```typescript
// Interface - best for objects
interface User {
  id: string;
  name: string;
  email: string;
}

// Type - best for unions
type Status = 'pending' | 'approved' | 'rejected';

// Type with union
type Response<T> = 
  | { success: true; data: T }
  | { success: false; error: string };
```

## Generics

Make reusable components with generics:

```typescript
function getArray<T>(arr: T[]): T {
  return arr[0];
}

const numbers = getArray<number>([1, 2, 3]);
const strings = getArray<string>(['a', 'b', 'c']);

// Generic Interface
interface Container<T> {
  value: T;
  getValue(): T;
}

const numberContainer: Container<number> = {
  value: 42,
  getValue() {
    return this.value;
  }
};
```

## Utility Types

TypeScript provides helpful utility types:

```typescript
interface Product {
  id: number;
  name: string;
  price: number;
  description: string;
}

// Make all properties optional
type PartialProduct = Partial<Product>;

// Make all properties required
type RequiredProduct = Required<Product>;

// Pick specific properties
type ProductPreview = Pick<Product, 'id' | 'name' | 'price'>;

// Omit specific properties
type ProductUpdate = Omit<Product, 'id'>;

// Make properties readonly
type ReadonlyProduct = Readonly<Product>;

// Extract keys as union type
type ProductKeys = keyof Product; // 'id' | 'name' | 'price' | 'description'
```

## Function Types

### Arrow Functions

```typescript
// Define function signature
type GreetFunction = (name: string) => string;

const greet: GreetFunction = (name) => {
  return `Hello, ${name}!`;
};

// Optional parameters
function optional(required: string, optional?: number): void {
  console.log(required, optional);
}

// Default parameters
function withDefaults(name: string = 'User', age: number = 18): void {
  console.log(`${name} is ${age} years old`);
}
```

## Error Handling

```typescript
type Result<T> =
  | { ok: true; value: T }
  | { ok: false; error: Error };

async function fetchUser(id: string): Promise<Result<User>> {
  try {
    const response = await fetch(`/api/users/${id}`);
    if (!response.ok) {
      return { ok: false, error: new Error('Failed to fetch') };
    }
    const data = await response.json();
    return { ok: true, value: data };
  } catch (error) {
    return { ok: false, error: error as Error };
  }
}

// Usage
const result = await fetchUser('123');
if (result.ok) {
  console.log('User:', result.value);
} else {
  console.log('Error:', result.error.message);
}
```

## Key Takeaways

- ✅ Always use explicit types
- ✅ Leverage interfaces and types appropriately
- ✅ Master generics for reusable code
- ✅ Use utility types for DRY code
- ✅ Handle errors with proper types
- ✅ Keep types organized and documented
