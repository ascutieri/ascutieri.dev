# Understanding Caching Strategies

Caching is critical for performance. Let's explore strategies.

## Cache Levels

```
┌─────────────────────────┐
│  Browser Cache          │ (CSS, JS, Images)
├─────────────────────────┤
│  CDN Cache              │ (Static content)
├─────────────────────────┤
│  Server Cache           │ (Redis, Memcached)
├─────────────────────────┤
│  Database Query Cache   │ (ORM level)
└─────────────────────────┘
```

## Cache Headers

```javascript
// Don't cache
res.set('Cache-Control', 'no-cache, no-store, must-revalidate');

// Cache for 1 hour
res.set('Cache-Control', 'public, max-age=3600');

// Cache indefinitely
res.set('Cache-Control', 'public, max-age=31536000, immutable');
```

## Strategies

| Strategy | Use Case |
|----------|----------|
| TTL | Temporary data |
| LRU | Limited memory |
| Write-through | Consistency critical |
| Write-back | Performance critical |

## Cache Busting

<!-- Add hash to filename -->
