# Accessibility Fundamentals: A11y Guide

Accessibility is not optional. It's essential for everyone.

## Semantic HTML

```html
<!-- ❌ Bad -->
<div onclick="navigate()">Click here</div>

<!-- ✅ Good -->
<a href="/page">Click here</a>
```

## ARIA Attributes

```html
<button aria-label="Close menu" aria-expanded="false">
  Menu
</button>

<div role="alert" aria-live="polite">
  Important message
</div>
```

## Color Contrast

```css
/* WCAG AA requires 4.5:1 ratio */
color: #000000;
background: #FFFFFF;
/* Ratio: 21:1 ✅ */
```

## Accessibility Checklist

| Item | Status |
|------|--------|
| Keyboard navigation | ✅ |
| Screen reader support | ✅ |
| Color contrast | ✅ |
| Form labels | ✅ |
| Alt text for images | ✅ |
