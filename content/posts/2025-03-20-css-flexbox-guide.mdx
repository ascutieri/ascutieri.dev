# Mastering CSS Flexbox Layouts

Flexbox is essential for modern CSS. Let's master it together.

## Basic Container

```css
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}

.item {
  flex: 1;
}
```

## Common Properties

```css
/* Alignment */
justify-content: center;      /* Horizontal */
align-items: center;          /* Vertical */
align-content: space-around;  /* Multiple lines */

/* Direction */
flex-direction: row;          /* Default */
flex-direction: column;       /* Vertical */
```

## Use Cases

| Use Case | Properties |
|----------|-----------|
| Navigation | flex-direction: row, justify-content: space-between |
| Centered Box | justify-content: center, align-items: center |
| Sidebar Layout | flex-direction: row, flex: 0 0 250px |
| Card Grid | flex-wrap: wrap, gap: 20px |

## Pro Tips

- Use `gap` for spacing instead of margins
- `flex: 1` makes items equal width
- `flex-shrink: 0` prevents item shrinking
