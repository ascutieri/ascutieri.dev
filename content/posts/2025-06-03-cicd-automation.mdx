# Continuous Integration and Deployment

CI/CD automates your workflow from code to production.

## GitHub Actions Example

```yaml
name: CI/CD

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - uses: actions/setup-node@v2
        with:
          node-version: '18'
      - run: npm install
      - run: npm test
      - run: npm run build
```

## Deployment Stages

```
Code Push
    ↓
Automated Tests
    ↓
Build Application
    ↓
Deploy to Staging
    ↓
Run Integration Tests
    ↓
Deploy to Production
```
