# Database Indexing Strategies

Proper indexing can dramatically improve query performance. Let's explore strategies.

## Types of Indexes

```sql
-- Single column
CREATE INDEX idx_email ON users(email);

-- Composite
CREATE INDEX idx_user_date ON posts(user_id, created_at);

-- Full text
CREATE FULLTEXT INDEX idx_content ON articles(title, body);
```

## Index Impact

```javascript
// Without index
Query time: 250ms
Full table scan

// With index
Query time: 2ms
Index seek
```

## Optimization Guidelines

| Scenario | Index Type |
|----------|-----------|
| WHERE clause | Single column |
| JOIN operations | Foreign keys |
| Sorting | ORDER BY column |
| Range queries | Composite index |

## When NOT to Index

- Columns with low cardinality
- Frequently updated columns
- Columns rarely used in queries
- Boolean columns
